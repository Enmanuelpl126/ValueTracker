# ValueTracker: Herramienta de Finanzas Conscientes

Crear una aplicación web interactiva que calcule el "costo por uso" de productos caros para fomentar compras más conscientes.

## Stack Tecnológico
- **Framework:** React (Vite)
- **Estilos:** Tailwind CSS
- **Iconos:** Lucide React
- **Componentes:** shadcn/ui (si es posible)
- **Animaciones:** Framer Motion

## Funcionalidades
1.  **Calculadora Core:**
    - Input de Precio.
    - Input de Frecuencia de uso (Mensual/Anual).
    - Cálculo en tiempo real del costo por uso.
2.  **Visualización Dinámica:**
    - Comparativa de costo (ej. "¿Cuesta más que un café al día?").
    - Mensajes motivadores según el resultado.
3.  **Interfaz Moderna:**
    - Diseño "Clean" y enfocado en la legibilidad.
    - Responsive para móviles.

## Pasos de Implementación
1. Inicializar proyecto con Vite.
2. Instalar dependencias (Tailwind, Lucide).
3. Crear componentes base (`Header`, `CalculatorCard`, `ResultDisplay`).
4. Implementar lógica de cálculo reactiva.
5. Pulir UI con animaciones y estilos finales.
