# 💰 ValueTracker

Una app web intuitiva para calcular el **costo real por uso** de cualquier producto o servicio. Descubre si realmente vale la pena esa compra analizando cuánto te cuesta cada vez que lo usas.


## 🚀 Cómo funciona

1. Ingresa el **precio** del producto
2. Indica cuántas veces lo **usarás** (en un período de tiempo)
3. Elige el período (mensual o anual)
4. Obtén el **costo real por uso** y consejos inteligentes

La aplicación te ayuda a tomar mejores decisiones de compra mostrándote si ese producto es una inversión inteligente o un gasto innecesario.

## 🛠️ Stack Tecnológico

- **React 19** - Biblioteca UI
- **Vite** - Herramienta de construcción rápida
- **Tailwind CSS** - Estilos utility-first
- **Framer Motion** - Animaciones fluidas
- **Lucide React** - Iconos modernos
- **ESLint** - Calidad de código

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar build
npm run preview
```

## 📝 Scripts disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run lint` - Valida la calidad del código
- `npm run preview` - Visualiza el build de producción

## 💡 Idea Principal

No se trata solo del precio de compra, sino de cuánto te cuesta realmente cada uso. Una laptop cara pero que usas 250 veces al año tiene un costo por uso muy bajo. Unas zapatillas baratas pero que casi no usas resultan ser caras por cada uso.
